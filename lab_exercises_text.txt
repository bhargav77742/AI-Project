These functions define four relationships between two people: parent, grandparent, 
sibling, and uncle. 
The parent() function returns True if x is the parent of y, and False otherwise. It 
does this by checking if either the father() or mother() predicate is true. 
The grandparent() function returns True if x is the grandparent of y, and False 
otherwise. It does this by first creating a new variable, temp. It then checks if x is the 
parent of temp and if temp is the parent of y. If both of these conditions are true, then 
the function returns True. Otherwise, it returns False. 
The sibling() function returns True if x and y are siblings, and False otherwise. It 
does this by first creating a new variable, temp. It then checks if x and y are both the
